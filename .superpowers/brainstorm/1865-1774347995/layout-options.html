界面布局选择

类似 markdowntoword.io 的合同审查前端，你喜欢哪种布局？

A

单栏居中

简洁垂直布局：顶部导航 → 上传区域 → 配置选项 → 转换按钮 → 结果区域

单栏布局示意
📁 拖拽文件到此处或点击上传
⚙️ 审查标准选择
开始审查
📄 审查报告预览
B

左右分栏

左侧：上传+配置 | 右侧：实时预览+进度显示

左右分栏示意
📁 上传区域
⚙️ 配置
👁️ 预览
📊 阶段 3/6: 智能体审查中...
C

向导式（多步骤）

分步引导：步骤1上传 → 步骤2配置 → 步骤3处理 → 步骤4完成

向导步骤示意
✓ 1.上传
✓ 2.配置
▶ 3.审查中
4.完成
🔄 正在执行第3阶段：智能体审查中...
